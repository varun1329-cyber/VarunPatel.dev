Privacy Policy

Your privacy is important to us.

EasyList collects and stores basic list items locally on your device. No personal information, contacts, location data, or usage tracking is ever collected or shared.

Stored Locally On Device:

  • 1. Item names
  • 2. Item creation timestamp
  • 3. Item completion status
  • 4. Total count of items
  • 5. Total count of completed items

All item data is saved strictly inside a JSON file within the app's documents directory.

Technical Architecture

Designed for resilience and privacy.

EasyList avoids remote backend dependencies and cloud sync complexity. Data remains 100% locally isolated inside the iOS Documents Directory.

  • JSON File Persistence: Maintained via EasyListData.json with automated pretty-printed encoding.
  • Atomic State Protection: Failed async operations trigger immediate state rollbacks to preserve list integrity.
  • Local Rating Persistence: In-app ratings and feedback comments are preserved in RatingFeedback.json.

// Duplicate Prevention Normalization
func normalizedItemName(_ name: String) -> String {
    var clean = name
        .trimmingCharacters(in: .whitespacesAndNewlines)
        .lowercased()

    if clean.hasSuffix("ies") {
        clean = String(clean.dropLast(3)) + "y"
    } else if clean.hasSuffix("es") && clean.count > 2 {
        clean = String(clean.dropLast(2))
    } else if clean.hasSuffix("s") && clean.count > 1 {
        clean = String(clean.dropLast(1))
    }
    return clean
}
