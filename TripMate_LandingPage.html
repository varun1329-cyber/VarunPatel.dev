Overview & Capabilities

Core Features

Everything you need to plan, track, and evaluate travel spending with confidence.

Multi-Currency & Resilient FX

Track in local currencies with automatic conversion back to your home currency via fallback APIs (`frankfurter.app`, `open.er-api.com`).

Per-Expense Conversion Snapshots

Prevents historic budget drift. Rates are locked at transaction time and stored securely inside encoded SwiftData Blobs.

Phase-Based Analytics

Automatically categorizes expenses by timeline into Pre-Trip, During-Trip, and Post-Trip visual phase charts.

Home-First Budget Management

Set overall and daily budgets in your home currency. Toggle budget tracking on or off anytime without deleting underlying expense data.

Control & Storage

Data Management & Breakdown

Comprehensive expense summaries, full local storage estimation, and total user data governance in Settings.

Spending So Far Breakdown

Interactive breakdown detailing home-paid amounts combined with converted foreign expenses alongside directly paid currency totals across all trips.

Destructive Reset Controls

Reset all application state securely. Confirmation dialogs detail exact counts of trips, expenses, and refund logs prior to execution.

On-Device Footprint

Built-in data usage estimator calculating real-time SwiftData model counts (Trips, Expenses, Refunds) and physical storage footprint on iOS.

Privacy Policy & Local Storage

Your travel financial data remains private.

TripMate persists all trips, expenses, and budget records directly on your device using Apple's SwiftData framework. No mandatory cloud sign-ins or user tracking.

Stored Locally On Device:

  • 1. Trip details (Name, destination, dates, budget snapshots)
  • 2. Expense entries (Title, amount, date, currency)
  • 3. Encoded per-expense conversion rate snapshots
  • 4. User preferences (Home currency, country profile)
  • 5. In-app feedback & rating logs (RatingFeedback.json)

External network access is strictly limited to fetching publicly available exchange rate tables (`api.frankfurter.app` / `open.er-api.com`). No trip names or financial amounts are uploaded to a server without explicit user action.

On-Device SwiftData Persistence

Zero server side databases. All relational records (`Trip` and `Expense`) are safely managed locally with native SQLite encryption support.

SwiftUI & SwiftData Architecture

Built natively for modern iOS.

TripMate relies on SwiftUI, SwiftData model containers, MapKit location autocomplete, and Swift 6 concurrency safety for smooth performance.

  • Thread-Safe FX Actor: actor CurrencyConversionService guarantees serialized cache access and network fallbacks.
  • Cascade Delete Rules: Trip models maintain standard cascade delete relationships to child Expense entities.
  • Location Search Integration: Debounced query searching using MKLocalSearchCompleter and CoreLocation.
ExpenseModel.swift (Phase Logic & Rate Locking) 
@Model
final class Expense {
    var id: UUID
    var title: String
    var amount: Double
    var date: Date
    var currency: String
    var conversionSnapshotStore: Data

    var phase: ExpensePhase {
        guard let trip = trip else { return .duringTrip }
        if date < trip.startDate { return .preTrip }
        else if date > trip.endDate { return .postTrip }
        return .duringTrip
    }
}
