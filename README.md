# Varun Patel — Personal Developer Portfolio

A clean, responsive, Apple-inspired personal portfolio website built with modern HTML5 and CSS. This portfolio highlights Varun Patel's journey as an independent iOS developer, featuring project highlights for apps like **EasyListApp** and **Trip Mate**.

---

## 🚀 Features

* **Apple-Style Minimalist Design:** Clean layout, dynamic typography using standard system fonts, high-contrast UI elements, and subtle background blur effects.
* **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile breakpoints using CSS Grid and Flexbox.
* **Accessibility First:** Includes a skip-to-content link, proper semantic HTML tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`), and SVG icons marked with `aria-hidden="true"`.
* **Performant & Lightweight:** Built using vanilla HTML5 and CSS without external frameworks or dependencies.
* **Modern CSS Techniques:** Utilizes CSS custom properties (variables), `clamp()` for responsive typography, and `backdrop-filter` for translucent header effects.
